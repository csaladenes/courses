The Kuramoto Model

We are now using the Kuramoto Model.

Unlike a simple "pulse", each agent continuously adjusts its speed based on the sine of the phase difference with neighbors. $$ \dot{\theta}_i = \omega_i + K \sum \sin(\theta_j - \theta_i) $$
