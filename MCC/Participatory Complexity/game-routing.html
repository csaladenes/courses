Bottlenecks & Queues

Every network node has a limited capacity. If packets arrive faster than they can be processed, a Queue forms.

If the queue fills up, packets are dropped. This creates latency and data loss, seen here as red packets vanishing.

The Braess Paradox

Adding more roads (or bandwidth) doesn't always help. If everyone chooses the "best" path, they might clog it, making it the "worst" path for everyone.
