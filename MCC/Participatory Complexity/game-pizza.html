Pareto Optimality

Is it possible to make one agent happier without making another agent sadder? If yes, the system is not yet Pareto Optimal. The simulation tries to find this state.

Deadlocks

If everyone is "Stubborn", the pizza never gets ordered. We need some "noise" (random concessions) to break the deadlock.
